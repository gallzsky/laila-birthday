## 🚀 Cara Deploy ke GitHub Pages

### Langkah 1: Buat Repository GitHub
1. Buka [github.com](https://github.com) → login
2. Klik **"New repository"**
3. Nama repo: `laila-birthday`
4. Set ke **Public**
5. Klik **"Create repository"**

### Langkah 2: Upload File
```bash
git init
git add .
git commit -m "💖 Happy Birthday Laila!"
git branch -M main
git remote add origin https://github.com/[username-kamu]/laila-birthday.git
git push -u origin main
```

### Langkah 3: Aktifkan GitHub Pages
1. Masuk ke repo → **Settings** → **Pages**
2. Source: **Deploy from a branch**
3. Branch: **main** → folder: **/ (root)**
4. Klik **Save**

Dalam 1-2 menit, website langsung online! 🎉
